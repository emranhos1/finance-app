## DFMS v1.1.3

### 🐞 Fixes
- **Backup failed with "mysqldump command not found"** — fixed. The app now finds MySQL on its own, wherever it is installed (C:, D:, E: or any other drive). It first asks the running MySQL server for its own folder, then checks the PATH, the Windows registry, and the usual MySQL / XAMPP / WAMP folders on every drive. No setup needed.
- If MySQL still can't be found, the backup error now says so clearly instead of suggesting an internet problem.

### 🔄 Changes
- **Release notes in English and Bangla:** "What's new?" now has **English | বাংলা** buttons. The app remembers the language you choose.

## DFMS v1.1.3

### 🐞 সমস্যা সমাধান
- **Backup-এ "mysqldump command not found" দেখিয়ে ব্যর্থ হতো** — ঠিক করা হয়েছে। MySQL যে drive-এই install করা থাকুক (C:, D:, E: বা অন্য যেকোনো), app এখন নিজেই খুঁজে নেয়। প্রথমে চালু MySQL-কেই তার ফোল্ডার জিজ্ঞেস করে, তারপর PATH, Windows registry আর প্রতিটা drive-এর সাধারণ MySQL / XAMPP / WAMP ফোল্ডারে দেখে। আলাদা কিছু করতে হবে না।
