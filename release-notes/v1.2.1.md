## DFMS v1.2.1

### 🐞 Fixes
- **Update progress bar was not visible** — fixed. While an update downloads, the bar now has its own space on the login screen and fills up as the download goes.
- **Download percentage:** the button now shows how much is done, for example `Downloading... 45%`.

Note: this shows from the next update onward, because the update screen belongs to the version that is already installed.

## DFMS v1.2.1

### 🐞 সমস্যা সমাধান
- **Update-এর progress bar দেখা যেত না** — ঠিক করা হয়েছে। Update download হওয়ার সময় login পাতায় bar এখন নিজের জায়গা পায়, আর download যত এগোয় bar তত ভরে।
- **Download কত % হলো:** বোতামে এখন দেখায় কতটা হয়েছে, যেমন `Downloading... 45%`।

খেয়াল করুন: এটা দেখা যাবে পরের update থেকে, কারণ update-এর পর্দা চলে আগে থেকে install করা version-এর কোডে।
