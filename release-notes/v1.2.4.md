## DFMS v1.2.4

### ✨ New
- **Cancel while backing up or connecting:** the logout popup now has a **Cancel** button while the backup is running and while it waits for Google sign-in. Cancel stops the backup (nothing is uploaded unless the upload had already started) or the sign-in attempt, closes the popup and keeps you logged in.
- **Press Enter to log in:** on the login screen, Enter now logs you in, so you no longer have to click **Login**.

### 🐞 Fixes
- **Register window was cut off:** the window was too short, so the security answer field and the **Register** button could not be seen. It now shows the whole form.
- **Login window stayed maximized after logout:** if the Dashboard was maximized, the login screen came back stretched across the whole screen. It now returns to its normal size.
- **Change Password closed on a mistake:** an empty new password, a mismatched confirmation or a wrong current password closed the window and you had to start again. Now the window stays open so you can correct it.
- **Adding a loan account** now asks for confirmation, like every other **Add** button.
- **Loans screen empty message:** the empty list now says **No loans yet** and tells you what to do next, instead of the confusing "No loan accounts yet" when people were already added.
- **Admin Panel:** the **Upload to Google Drive** button text was cut off. The Google Drive buttons now move to the next line when the space is narrow.

### 🔧 Behind the scenes
- Removed unused code and styles. Nothing changes in how the app works.

## DFMS v1.2.4

### ✨ নতুন
- **Backup বা Google সংযোগের সময় Cancel:** logout popup-এ এখন backup চলার সময় আর Google sign-in-এর অপেক্ষার সময়ও **Cancel** বোতাম আছে। Cancel চাপলে backup (upload আগেই শুরু না হয়ে থাকলে কিছু upload হয় না) বা sign-in-এর চেষ্টা থেমে যায়, popup বন্ধ হয়, আর আপনি logged in থাকেন।
- **Enter চেপে login:** login screen-এ এখন Enter চাপলেই login হয়, **Login** বোতামে click করতে হয় না।

### 🐞 সমস্যা সমাধান
- **Register window কেটে যেত:** window ছোট ছিল, তাই security answer-এর ঘর আর **Register** বোতাম দেখা যেত না। এখন পুরো form দেখা যায়।
- **Logout-এর পর login window maximize থেকে যেত:** Dashboard maximize করা থাকলে login screen পুরো পর্দা জুড়ে বড় হয়ে ফিরত। এখন স্বাভাবিক মাপে ফেরে।
- **Change Password ভুলে বন্ধ হয়ে যেত:** নতুন password খালি, confirm না মেলা বা বর্তমান password ভুল হলে window বন্ধ হয়ে যেত, আবার গোড়া থেকে শুরু করতে হতো। এখন window খোলা থাকে, ভুল ঠিক করে আবার চাপা যায়।
- **Loan account যোগ করার আগে** এখন confirm চায়, অন্য সব **Add** বোতামের মতো।
- **Loans screen-এর খালি তালিকার লেখা:** মানুষ যোগ করা থাকলেও "No loan accounts yet" লেখা দেখাত, যা বিভ্রান্তিকর। এখন লেখা আছে **No loans yet** আর পরের ধাপ কী তা বলা আছে।
- **Admin Panel:** **Upload to Google Drive** বোতামের লেখা কেটে যেত। জায়গা কম হলে Google Drive-এর বোতামগুলো এখন পরের লাইনে নেমে যায়।

### 🔧 ভেতরের কাজ
- অব্যবহৃত code আর style সরানো হয়েছে। app-এর কাজে কোনো পরিবর্তন নেই।
