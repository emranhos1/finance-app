## DFMS v1.2.3

### 🐞 Fixes
- **Logout backup error was cut off** — fixed. When **Backup Now** fails during logout, the popup now grows to fit the whole message, so nothing overlaps and every button stays visible.
- A very long error message now scrolls inside the popup, so it can be read in full.
- **Cancel button in the logout popup:** you can now close the popup and go back to the app without logging out, including after an error.
- **Login window size after logout:** minimizing the login window and opening it again from the taskbar no longer makes it bigger.

## DFMS v1.2.3

### 🐞 সমস্যা সমাধান
- **Logout-এর সময় backup-এর error কেটে যেত** — ঠিক করা হয়েছে। Logout-এর সময় **Backup Now** ব্যর্থ হলে popup এখন পুরো বার্তার মাপে বড় হয়, তাই কোনো লেখা একটার উপর আরেকটা পড়ে না, আর সব বোতাম দেখা যায়।
- Error-এর বার্তা খুব লম্বা হলে popup-এর ভেতরে scroll করে পুরোটা পড়া যায়।
- **Logout popup-এ Cancel বোতাম:** এখন popup বন্ধ করে logout না করেই app-এ ফিরে যাওয়া যায়, error আসার পরেও।
- **Logout-এর পর login window-এর মাপ:** login window minimize করে taskbar থেকে আবার খুললে এখন আর বড় হয়ে যায় না।
