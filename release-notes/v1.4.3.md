## DFMS v1.4.3

### 🎨 Improvements
- **Same look for every confirmation pop-up:** when the app asks "Add…?", "Update…?", "Delete…?", "Save…?" (accounts, loans, transfers, transactions, categories, backups), OK and Cancel are now the same size, side by side, and Cancel is red.
- **Same look for every message pop-up:** errors, "All fields are required" and success messages now show one wide OK button, and long messages wrap inside the box.

### 🐞 Fixes
- **Update folder:** when you update from the Dashboard, the folder picker now opens in the folder you used last time, instead of the Windows Downloads folder.

## DFMS v1.4.3

### 🎨 উন্নতি
- **সব নিশ্চিতকরণ পপআপের একই চেহারা:** অ্যাপ যখন জিজ্ঞেস করে "Add…?", "Update…?", "Delete…?", "Save…?" (account, loan, transfer, transaction, category, backup), তখন OK আর Cancel এখন সমান মাপের, পাশাপাশি, আর Cancel লাল।

### 🐞 সমস্যা সমাধান
- **Update-এর ফোল্ডার:** Dashboard থেকে update করলে ফোল্ডার-বাছাই এখন আপনার শেষ ব্যবহার করা ফোল্ডারে খোলে, Windows-এর Downloads-এ নয়।
