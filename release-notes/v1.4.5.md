## DFMS v1.4.5

### ✨ New
- **Day-wise totals on the Transaction page:** the transaction table is now grouped by day. Every day has a header row with the date and weekday and that day's **Income** and **Expense** totals.
- **Open and close a day:** click a day's header to show or hide its transactions. All days start closed, so you see the daily totals first.

### 🎨 Improvements
- **Paging by day:** the page now holds a number of days (**Days per page**, default 10), so one day is never split over two pages and its totals are always complete.
- **Clearer table columns:** the Transaction table now has Date, Account, Category, **Income**, **Expense** and Note. An amount sits in the Income or Expense column, so the separate Type and Amount columns are gone. The columns fit the window without a horizontal scroll bar.

## DFMS v1.4.5

### ✨ নতুন
- **Transaction পেজে দিন-ভিত্তিক যোগফল:** transaction-এর table এখন দিন ধরে সাজানো। প্রতিটা দিনের একটা header row আছে, যাতে তারিখ, বার আর ওই দিনের **Income** ও **Expense** এর যোগফল দেখা যায়।
- **দিন খোলা ও বন্ধ করা:** কোনো দিনের header-এ ক্লিক করলে ওই দিনের transaction গুলো দেখা বা লুকানো যায়। শুরুতে সব দিন বন্ধ থাকে, তাই আগে দিনের যোগফলই চোখে পড়ে।

### 🎨 উন্নতি
- **দিন ধরে page:** এখন একটা page-এ কয়েকটা দিন থাকে (**Days per page**, শুরুতে ১০)। তাই একটা দিন দুই page-এ ভাঙে না, আর তার যোগফল সবসময় পুরো থাকে।
- **পরিষ্কার column:** Transaction table-এ এখন Date, Account, Category, **Income**, **Expense** আর Note। টাকা Income বা Expense column-এ বসে, তাই আলাদা Type আর Amount column আর নেই। Column গুলো জানালার মাপে খাপ খায়, নিচে আড়াআড়ি scroll bar লাগে না।
