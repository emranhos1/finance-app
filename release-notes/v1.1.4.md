## DFMS v1.1.4

### 🔄 Changes
- **Update download folder is remembered:** after clicking **Update now**, the folder picker now opens where you saved the previous update, so there is no need to browse to it every time.
- **No repeated downloads:** if that folder already has this version's installer (for example, the install was cancelled last time), it is checked and reused instead of being downloaded again.

## DFMS v1.1.4

### 🔄 পরিবর্তন
- **Update download-এর ফোল্ডার মনে থাকে:** **Update now** চাপার পর ফোল্ডার বাছাইয়ের ঘর এখন সেই ফোল্ডারেই খোলে, যেখানে আগের update রাখা হয়েছিল। প্রতিবার খুঁজে খুঁজে যেতে হবে না।
- **একই ফাইল বারবার download হয় না:** ওই ফোল্ডারে এই version-এর installer আগে থেকেই থাকলে (যেমন গতবার install মাঝপথে বাতিল করা হয়েছিল), app সেটা ঠিক আছে কি না যাচাই করে, তারপর আবার না নামিয়ে সেটাই চালায়।
